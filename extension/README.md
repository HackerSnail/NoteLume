# NoteLume 剪藏（浏览器扩展）

把网页正文剪藏到本机 NoteLume 知识库：按模板落盘成标准 GFM md，图片进 `assets/`，文末自动追加「## 相关笔记」关联库内已有文档。

MV3，无构建、无 npm 依赖。`vendor/` 下是两个原样放入的库：

- `Readability.js` —— @mozilla/readability 0.5.0（Apache-2.0）
- `turndown.js` —— turndown 7.2.0（MIT）

## 安装

Edge / Chrome：开 `edge://extensions`（或 `chrome://extensions`）→ 打开左下角「开发人员模式」→「加载已解包的扩展」→ 选本目录。

## 配置

右键扩展图标 →「扩展选项」（或 `edge://extensions` 里点详情 → 扩展选项）：

- 服务器地址：NoteLume 剪藏设置里显示的地址，默认 `http://127.0.0.1:3210`。端口被占用顺延过就以 NoteLume 里显示的实际端口为准
- 访问令牌：NoteLume 剪藏设置里生成的那一串 32 位十六进制
- 默认目标目录 / 默认模板：可选，填了就对每次剪藏生效，覆盖 NoteLume 设置里的对应值

「测试连接」会请求 `GET /health`，能看出服务在不在、端口对不对、NoteLume 有没有开着知识库。

NoteLume 侧：工具条「更多 → 网页剪藏设置」里启用服务、生成令牌、选模板与目标目录。

## 使用

- 点工具栏图标：剪藏整页
- 右键菜单「剪藏选中内容到 NoteLume」：只剪选中的片段（先在页面上选中文字）
- 右键菜单「剪藏整页到 NoteLume」：同工具栏图标

处理中图标徽标转圈，成功 / 失败都有系统通知，通知里带落盘路径、图片数与关联篇数。

## 失败提示对照

| 提示 | 原因 |
| --- | --- |
| 连不上 NoteLume | 应用没启动，或剪藏服务没启用，或地址端口不对 |
| 令牌不匹配 | NoteLume 里重新生成过令牌，选项页要同步改 |
| 请先打开一个知识库 | NoteLume 开着但没开库 |
| 内容超过大小上限 | 单次载荷超 8MB、正文超 2MB、单图超 5MB |
| 没有选中内容 | 选了「剪藏选中内容」但页面上没有选区 |

## 安全边界

服务只绑 `127.0.0.1`，请求要带令牌；`Origin` 不是扩展来源、`Host` 不是回环名的请求一律被 Rust 侧拒绝。令牌只存 NoteLume 的 settings.json 与浏览器本地存储，不外传。
