三个理由

该有的都有，
不该背的没有。

所写即所得

Markdown 与富文本双向无损往返。KaTeX 公式、Mermaid 图表、合并单元格表格，都在渲染态直接编辑，不用切源码模式。

文件夹即知识库

[[双链]] 输入补全、#标签 全局视图、双向链接、全库搜索、Canvas 知识图谱——都对着你自己的文件夹干活。

完全本地，零锁定

纯 GFM 文件，Typora 和 Obsidian 能直接打开同一份库。默认不联网、不上传，删除进系统回收站；要接大模型时自己填 API 端口，数据直达你配置的服务。

粘贴

粘贴即净。从 AI 对话框、飞书、公众号复制的内容，
进编辑器前就摘掉杂质。 代码块的「复制」按钮、行号装订线、空段落串联，在写入前自动清理，不用粘完再手修第二遍。

Quarkdown

让笔记可编程。.var、.foreach、.if
直接写进 Markdown，约 200 个内置函数。 快照式预览，光标移出指令区即出结果，源文件一个字节不动。不用指令的文档仍是纯 GFM。

Git

Git 长在里面。状态、历史、diff、提交、冲突解决，
全部内建。 git2 引擎，机器上没装 git 也能 fetch 和 pull。Word 导入同样离线直读，落库前可视化校对。

功能

网页剪藏

浏览器扩展一键把网页正文存进本地库，图片按内容去重进 assets/，文末自动关联库内相关笔记。

功能

Quarkdown 引擎收官

五阶段做完，Rust 版 stdlib 对 Kotlin 参考实现的函数差集清零，.var、.foreach 直接写进 md。

导出

整库幻灯片

库内全部 md 合成一份自包含的 reveal.js 放映件，外层按文档分章、内层上下翻页。

导出

标准 Markdown 副本

整库导出时 Obsidian 私有语法自动降级，产物任何编辑器都能打开，目录结构原样保留。

体验

粘贴自动清理

从 AI 对话框、飞书、公众号复制的内容，进编辑器前就摘掉「复制」按钮和空段落。

体验

视觉行号装订线

WYSIWYG 模式按折行后的视觉行连续编号，虚拟化渲染，5 万字单段实测流畅。

兼容

块级裸 HTML

WordPress 一类工具导出的 md 原样保住并渲染出排版，不再满屏字面标签。

修复

Ctrl+Tab 切标签失灵

键位校验只认大写 Tab，事件反解产出小写，链路在校验层就断了——现已归一。
