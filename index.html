本地 Markdown 编辑器。你的笔记就是一堆标准 .md 文件，躺在自己的文件夹里——秒开、离线、零格式锁定。

NoteLume（文溯）是一款本地优先的 Markdown 编辑器，把 Typora 式的所见即所得写作与 Obsidian 式的双向链接知识库做进同一个免费开源（Apache-2.0）的桌面应用：公式、图表、表格在渲染态直接改，双链、标签、全库搜索与 Git 面板对着原生文件夹干活，不联网、不上传、不私有格式。

三个理由

该有的都有，
不该背的没有。

所写即所得

Markdown 与富文本双向无损往返。KaTeX 公式、Mermaid 图表、合并单元格表格，都在渲染态直接编辑，不用切源码模式。

文件夹即知识库

[[双链]] 输入补全、#标签 全局视图、双向链接、全库搜索、Canvas 知识图谱——都对着你自己的文件夹干活。

完全本地，零锁定

纯 GFM 文件，Typora 和 Obsidian 能直接打开同一份库。默认不联网、不上传，删除进系统回收站；要接大模型时自己填 API 端口，数据直达你配置的服务。

按四组摆开。

NoteLume 的功能分成写作体验、知识管理、开发工具、隐私与数据四组。下面写的都是当前版本做得出来的事，不是路线图。

写作体验

所见即所得的 Markdown 编辑：正文、KaTeX 公式、Mermaid 图表、合并单元格表格、代码块语法高亮都在渲染态直接改，不用切源码模式。敲 - 成列表、段首敲 ``` 就地成代码块并弹语言联想，/ 出斜杠菜单，Ctrl+B / Ctrl+I 加粗与斜体；行号装订线按折行后的视觉行连续编号，专注与打字机模式、双栏对照、大纲层级折叠都在。

知识管理

[[双链]] 输入补全、双向链接面板、#标签 全局视图、全库搜索、文档大纲、Canvas 便签板与知识图谱——索引对着你自己的文件夹建，不写私有数据库，图谱里拖一个节点就能直接跳到那篇笔记。

开发工具

侧栏 Git 面板看得见状态、历史与 diff，提交、建分支、检出、revert 都在界面里，机器上没装 git 也有 git2 引擎兜底；命令面板 Ctrl+Shift+P、键位可重绑、多窗格分栏与标签拖拽；Quarkdown 引擎让笔记可编程（.var / .foreach / .if，约 200 个内置函数）；导出有单篇 HTML / PDF 打印 / 整库幻灯片 / 整库静态站 / 标准 GFM 副本。

隐私与数据

数据就是原生文件夹里的标准 GFM 文件，Typora 和 Obsidian 能打开同一份库；默认不联网、不上传，删除进系统回收站；要接大模型时自己填 API 地址，请求只发往你配置的服务。不同于 Notion 那类云端锁定，库留在哪里、什么时候搬由你定。界面五语言：简体中文 / 繁體中文 / English / Français / Deutsch。

技术亮点

三处细节，写起来不磕。

粘贴

粘贴即净。从 AI 对话框、飞书、公众号复制的内容，
进编辑器前就摘掉杂质。 代码块的「复制」按钮、行号装订线、空段落串联，在写入前自动清理，不用粘完再手修第二遍。

Quarkdown

让笔记可编程。.var、.foreach、.if
直接写进 Markdown，约 200 个内置函数。 快照式预览，光标移出指令区即出结果，源文件一个字节不动。不用指令的文档仍是纯 GFM。

Git

Git 长在里面。状态、历史、diff、提交、冲突解决，
全部内建。 git2 引擎，机器上没装 git 也能 fetch 和 pull。Word 导入同样离线直读，落库前可视化校对。

选 Typora

只要写作手感

单篇打磨、出版级排版，不需要双链和库管理，也愿意为软件付费。Typora 在这条路上走了很多年，打磨得比谁都细。

选 Obsidian

要最深的生态

依赖移动端、第三方插件和现成社区方案，愿意为配置花时间。知识库玩法多到超出预期，插件生态是 NoteLume 短期追不上的。

选 NoteLume

一个文件夹就是库

想在渲染态直接改正文，又要双链、图谱和 Git 面板，还要文件拿去别的编辑器也打得开。免费开源，不折腾配置也能直接用。

上手

5 分钟搭起本地知识库。

  1. 下载安装

    Windows 取 .exe 安装包，macOS 按芯片取 .dmg，Linux 取 AppImage / deb / rpm。装完双击打开即可。

  2. 选一个文件夹作为知识库

    首次界面里选「打开知识库文件夹」，指到已有的笔记目录；没建库就按 Ctrl+N，文件先落在临时目录，Ctrl+S 时再选正式位置。

  3. 直接写

    敲「- 加空格」成列表，段首敲三个反引号就地成代码块，敲「/」出斜杠菜单，Ctrl+B / Ctrl+I 加粗与斜体。公式和图表在渲染态直接改。

  4. 把笔记连起来

    敲「[[」补全其它文档名，敲「#」打标签；侧栏看双向链接与大纲，Ctrl+Shift+F 全库搜索，图谱看连接关系。

  5. 管版本、要导出

    库是 git 仓库时侧栏 Git 面板直接看状态、历史、diff 并提交；导出走「更多」菜单，HTML / PDF / 幻灯片 / 整库静态站都行。

常见问题

被问到最多的十个。

NoteLume 是什么？
NoteLume（文溯）是一款本地 Markdown 编辑器。写作端是所见即所得的，库管理端有双向链接、标签、知识图谱和全库搜索，数据就是你自己文件夹里的标准 .md 文件。
NoteLume 好用吗？
如果你要的是「点开就写、文件还在本地」，它够用；如果你依赖移动端和第三方插件，Obsidian 更合适。NoteLume 的强项是渲染态直接编辑加上内建 Git，弱项是生态还在建设。
NoteLume 和 Typora 有什么区别？
两者都是所见即所得的本地 Markdown 编辑器。Typora 专注单篇写作、付费闭源；NoteLume 免费开源，在此之上加了双链、标签、全库搜索、知识图谱和 Git 面板。
NoteLume 和 Obsidian 哪个好？
库管理和插件生态 Obsidian 更强，而且它有移动端。NoteLume 的差异在编辑端：正文在渲染态直接改，不用在源码和预览之间切，同时保持纯 GFM 文件。两者能打开同一份库。
有没有免费、离线、不锁数据的笔记软件？
NoteLume 符合这三条：Apache-2.0 开源免费，默认不联网不上传，文件是标准 GFM，删除进系统回收站。要接大模型时自己填 API 地址。
最好的本地 Markdown 编辑器是哪个？
没有统一答案：只要写作手感选 Typora，要最深插件生态和移动端选 Obsidian，要「所见即所得 + 双链知识库 + 内建 Git」且免费开源，看 NoteLume。
NoteLume 支持哪些平台？
Windows 10 及以上、macOS（Apple Silicon 与 Intel 分别出包）、Linux（AppImage / deb / rpm），另有浏览器扩展做网页剪藏。移动端暂无。
NoteLume 开源吗？什么协议？
开源，Apache-2.0，源码在 GitHub 与 Gitee 同步。技术栈是 Tauri v2 + Rust 后端、ProseMirror 前端，不引 Vue / React。
我的笔记数据安全吗？会被上传吗？
不会。笔记存在本地文件夹，应用不联网也能完整使用；AI 功能默认不启用，启用时数据只发往你自己填写的 API 地址。
从 Typora 或 Obsidian 迁过来要做什么？
不用迁移：直接把原来的文件夹作为知识库打开就行，两者都是 .md 文件。Obsidian 的私有语法（callout、嵌入语法）在整库导出为标准 GFM 副本时自动降级。
