# NoteLume 又攒了一大波更新

上次发 0.10 的时候，这软件其实还只是个能写能存、能双向链、能把 Word 拖进来的本地 Markdown 编辑器。发了之后我自己天天用，越用越觉得哪儿别扭——不少事做得太糙。这阵子（其实也就十来天）基本没干别的，就是把我自己用着不爽的地方挨个填了。下面按我自己的使用顺序说。

## 编辑区终于能分栏了

之前一屏就一个文档，想对照着另一篇改点东西，得来回切；想把 A 窗格里的文档挪到 B 窗格，得在 B 里重新打开一遍。这回编辑区拆成了 SplitPane 树，左右、上下随便拆，拆出来的每个窗格各带一条自己的标签条，一个窗格里能开多篇文档来回切，各自的根、脏状态、保存互不影响。

拖标签也能拖着摆了：标签拖到另一个窗格中间是挪过去，拖到窗格边缘的四分之一处是在那一侧拆出新窗格，拖回自己窗格是重排顺序；文件树里的文件直接拖进某个窗格，就在那个窗格打开。布局比例拖完会存进设置，重启还在。

我比较看重的一点是拆分不重建 DOM——拆和关只搬动一个元素，ProseMirror 的选区不会连根拔起。之前无头环境测出来过几个坑，比如 50% 的比例实际渲成 75%、嵌套拆分后样式刷到已搬走的元素上，都补了对应的单测盯住。


## 浏览器里看到什么，一键存进库

这是个完整的网页剪藏链路：装个浏览器扩展，在页面上点一下（或者选中一段右键），内容就经本地 HTTP 服务送到 Rust 侧，按你设的模板落进知识库，还会自动翻出相关的已有笔记挂在文末。

中间踩了不少坑。比如 Defuddle 提取失败时会把整个 body 当正文塞回来，工具栏图标又不认选区，结果「只能剪整页」；再比如博客园这类平台会在正文尾巴挂一段「本文作者 / 版权声明 / posted @ 阅读(…)」的签名块，剪下来结尾全是噪声。这两类都针对性修了——提取失败先降级 Readability，再不行才认整页；签名块从结尾往前扫，命中就切掉。提取器换成四级优先级（Defuddle 优先，不行降级），图片本地化改成默认关的开关，外链图在离线场景会裂，但速度更快。

扩展侧还有个框选截图：页面上拖个矩形，把那一块画面截下来存进笔记。选区截图只能圈文字，图、图表、canvas 画出来的东西划不出来，框选补的就是这一段。

## 库里的文件改了，软件自己知道

以前在文件管理器里把某篇文档删了、改了名、移了位置，NoteLume 里的侧边栏树纹丝不动，得手动重开知识库才能看到。这回 Rust 侧加了个文件系统监听，基于 notify，独立线程跑、防抖 500ms、忽略隐藏文件和 assets 目录，库里任何增删改都会触发事件，前端自动重扫树、刷新状态栏。换库时旧的监听自动停掉，不留孤儿。

连带把之前几个「库外删了文档之后点树里那行会崩」的毛病一起收拾了：报错文案不再甩 errno 原文（现在写「文件已不存在：{path}」），点了已删的行会重扫把死行去掉，不会再整棵树没反应。


## 编辑器手感这一轮修得最狠

这回改得最多的其实是「用着不对劲」的小地方，列几个我自己踩的：

- 光标在表格单元格里按回车出不去、块首按退格吞掉上一整块、标题回车莫名其妙多出一个空标题——四条链路各断一处，分别改了退格的回退逻辑、表格 Enter 走下一格或末格出表、标题回车把后半段降到下方新段落。
- `**总结：**大` 这种中文加粗不渲染，保存一次 `**` 还被转义改坏。根子是 CommonMark 的 flanking 判定假设按空白分词，全角冒号挨着星号不算贴合。改法是在 tokenizer 计算贴合时把非 ASCII 标点临时掩码成普通文字，放宽只此一类，ASCII 标点照旧按规范。
- 源码和所见即所得切换光标乱跳、视图不跟光标走，是滚动和焦点时序的问题，加了层序列化记账把两边选区双向映射。
- 表格空行比光标还矮、上下方向键不能跨行移格、编辑区右键会冒出 WebView2 原生菜单——都收了。



## 现在到什么程度了

距离上次发的 0.1.0，这波主要把「能写」补成了「写得顺、存得稳、跟别的工具能来回倒」。多窗格、剪藏、Git 远程、插件同意、Word 公式与交叉引用，这些都是这次新有的；编辑器那一堆手感问题是这次重点修的。
