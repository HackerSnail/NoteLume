- **构建方式**：仓库根 `npm run dev`（tauri dev 调试构建）
- **用例日期**：2026-11-01
- **执行人**：AI（computer-use 像人一样操作）
- **测试结果口径**：通过 / 不通过 / 未测试
- **专用测试库**：`C:\Users\Administrator\Desktop\nl-vault-test`（含预置 md / 图片 / 子目录）

> 通用前置条件（除特殊说明外均默认满足）：
> 1. NoteLume 桌面应用已成功编译并启动，窗口正常显示；
