# 表格、任务与折叠

这篇专放「结构化」的写法。数据从 Word 或 Excel 复制过来通常就长这样。

## 表格

对齐靠分隔行的冒号，单元格里的 `<br>` 可以换行。

| 模块 | 负责什么 | 快捷键 | 状态 |
| :--- | :--- | :---: | --- |
| 文件树 | 库内浏览与拖拽移动 | — | 可用 |
| 源码模式 | 原文编辑，带高亮与行号 | `Ctrl+E` | 可用 |
| 知识图谱 | 全站链接关系 | — | 可用 |
| Git 集成 | 提交 / 拉取 / 冲突解决 | — | 桌面版才有 |

单元格可以合并吗？GFM 表格是矩形结构，不能合并——真拿到不规则表格时，
导入环节会先做矩形归一，避免整列错位（见 [[code-math]] 里的说明）。

## 任务列表

- [x] 扫描建库（链接 / 标签 / 标题）
- [x] 反链与图谱
- [ ] 把 [[尚未存在的页面]] 补上
- [ ] 给团队写完规范 #能力/表格

点方括号即可勾选，状态直接写回 Markdown 源文件，不存在别处。

## 折叠

标题可以折叠：把光标放到 `## ` 这一行，左侧出现箭头，点它收起整节；
按 `Ctrl+Shift+…` 系列键能按层级批量折叠。展开状态不写进文件，
所以同一篇文档在 Typora / Obsidian 里打开长得一样。

## 分栏对照

左边写、右边看：`Ctrl+Shift+E` 切单双栏，`Ctrl+Alt+←/→` 在窗格间跳焦点。
详细的双链行为看 [[wiki-links]]，公式与代码在 [[code-math]]。
