# 标签与文档属性

这篇同时演示两件事：文件开头的 YAML frontmatter，以及正文里的多级标签。

## 文档属性从哪来

开头那段 `---` 包围的 YAML 会显示在右侧「文档属性」面板里，可以直接编辑：
`title` 决定列表与标题栏显示的标题（没有它则取第一个一级标题），
`tags` 是 Obsidian 那套写法，`owner` / `draft` 这类自定义键原样保留，不会被吞掉。

这段元数据就是普通文本，写进 `.md` 文件本身——换个编辑器打开还在。

## 多级标签

正文里写 `#能力/标签/嵌套` 这样的斜杠路径，标签面板会按层级聚合成树；
点标签名筛选，命中列表来自扫描结果而不是数据库。

同一条标签写多次只算一次；下面这几条是本页要给全站标签面板贡献的计数：

- #能力/标签
- #能力/标签/嵌套
- #开始/演示

标题行里的 `#能力/标签` 不会被当标签（那行本来就该是标题）；
围栏代码块里的井号也不抽——见 [[code-math]] 的示例块。

## 与链接的分工

一句话：链接表达「这一篇和那一篇有关系」，标签表达「这一类东西放一起」。
两边在图谱里是两套数据：节点和边来自 [[wiki-links]] 那套链接扫描，
标签只在面板与筛选里出现。

想试写完标签后的即时反应，在正文任意处新写一行 `#临时/试一下`，
右侧标签面板会跟着刷新；删掉它就消失（状态不落盘）。
