# 双向链接与引用

双链是知识库跟单篇笔记最本质的区别：写完不用整理，关系自己长出来。

## 三种写法

页面名直接包起来就是链接，`[[tables-tasks]]`；再加竖线可以换显示文字，
比如 [[code-math|代码与数学这一篇]]。想跳到具体小节，用 `#` 接标题：
[[home#在这里可以做什么]]。

不存在的页面也会被记住，点它会新建——[[又一个没写的页面]]。

## 反向链接从哪来

[[home]] 里链向了这里，所以本页的反链列表会出现首页；同时本页指出去
（[[tables-tasks]]、[[code-math]]、[[home]]）也进「本文档引用」。
两边都是扫描出来的，没有任何手工维护的索引文件。

悬停在本页任意链接上，会浮出目标文档的摘要；点开则在当前窗格替换，
按住 `Ctrl` 点开则新开窗格。

## 与标题、锚点的关系

标题本身就是锚点，正文里的 `[[home#语法快速一览]]` 跳过去会滚动到那张表格。
文件改名或移动后链接依然有效：解析按库内相对路径重算，不写绝对路径。
